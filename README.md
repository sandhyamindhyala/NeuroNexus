# NeuroNexus - Task 1: Responsive Landing Page

This is Task 1 of the Web Development Internship offered by **NeuroNexus Innovations**.

## 🔰 Task Objective

Build a responsive, Google Form-like web form using **only HTML and CSS** (no JavaScript).

### 🔧 Features

- Collects the following details:
  - Full Name
  - Contact Number
  - Address
  - Company Name
  - Email Address
  - Department (HR, Sales, Development, Marketing, Others)
  - Gender (Male, Female, Prefer not to say)
- Submit Button
- Responsive layout for mobile, tablet, and desktop
- Beautiful and minimal UI using:
  - Hover effect on the submit button
  - Distinct form background
  - Box-shadow for depth

## 📁 Files Included

- `index.html` – The form structure
- `style.css` – Styling and responsive design
